# Beach Read

Тренажёр чтения защиты в пляжном волейболе. React, TypeScript, Vite и Three.js. Работает самостоятельно, без зависимости от соседнего okbz-model и без серверного хранилища.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Vite показывает адрес после запуска. Сервер слушает `0.0.0.0`, поэтому доступен в локальной сети. Порт по умолчанию 5173; занятый порт Vite заменяет следующим.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Публиковать нужно содержимое этой папки через HTTPS. Публичное размещение в рамках этой реализации не выполнялось.

## Как устроена тренировка

В главном меню выбираются тип теста, время показа, время ответа, длительность, ракурсы и позиции. Один раунд состоит из наблюдения и выбора зон. Между раундами есть настраиваемый перерыв: 0 / 0,5 / 1 / 2 / 3 секунды, по умолчанию 1 секунда. После последнего ответа перерыва нет. Общее время включает паузы; старые результаты без этой настройки воспроизводятся без пауз. Длительность округляется вверх до целого числа раундов; предстартовый отсчёт не входит в неё. Следующая сцена готовится скрыто во время ответа.

Успех засчитывается за любой непустой набор слабых зон без закрытых. Обычная слабая зона даёт 1 очко и отмечается голубым, очень слабая даёт 2 очка и сохраняет зелёный цвет. Очки выбранных зон складываются; ошибочная зона обнуляет очки раунда. Время первого выбора сохраняется отдельно от итогового набора. Пропуски не входят в медиану времени ответа. При скрытии вкладки тест прерывается без сохранения.

В `src/scenarios.ts` находятся 48 ситуаций. Блок появляется только при атаке у сетки: с песка либо в прыжке, всегда перед точкой атаки. Атаки со средней и дальней дистанции проходят против двух защитников без блока. Игрок на боковой или лицевой линии показан в движении. Любой бегущий игрок направлен к центру части поля, не закрытой вторым игроком; цель сдвинута от центра поля на треть расстояния до лицевой линии. Позы статичны. Подбор не повторяет сцену до исчерпания подходящего набора. Практика возвращает ошибки без таймера и после ответа показывает позиции и направления соперников; реплей восстанавливает сцены, параметры и нажатия. Кнопка `Все ситуации` внизу открывает весь каталог: сначала показывается POV, затем схема со всеми отмеченными правильными и ошибочными зонами.

Высота глаз, подъём в прыжке и высота сетки влияют только на изображение. Приложение показывает свободное пространство, не моделирует полёт мяча и не определяет возможность конкретного удара. Разметка ситуаций пока не проверена тренером.

Пресеты сетки взяты из [правил FIVB 2025–2028, пункт 2.1](https://www.fivb.com/wp-content/uploads/2025/02/FIVB-BeachVolleyball_Rules2025_2028-EN-v01.pdf#page=15). Оформление и проверки опираются на [UX/UI Agent Skills](https://github.com/plugin87/ux-ui-agent-skills). Часть линейных иконок использует пути Lucide; логотип поля собственный.

## Данные и офлайн

Настройки и история хранятся в localStorage на устройстве в версионированном формате. Сохраняются снимки сцен, поэтому обновление каталога не изменяет старые реплеи. Сброс настроек не удаляет историю. При ошибке чтения история не перезаписывается; её можно удалить отдельно с подтверждением.

PWA кэширует код, стили и иконки после первой полной загрузки. Интернет для самого теста не требуется. Установка и service worker работают через HTTPS или localhost, в production-сборке. Обновление предлагается вне активного теста. Поделиться можно текстом или локальной PNG-карточкой; системная отправка зависит от браузера.

## Проверки

```sh
npm test
npx playwright install chromium
npm run dev
# В другом терминале:
npm run test:e2e
```

Если сервер использует другой порт, задайте `TEST_URL`. Для уже установленного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

- Unit-тесты проверяют зачёт, округление времени, каталог и фильтры, последовательности сцен, валидацию истории и реплей.
- Браузерные тесты проверяют настройки, ширины 280–768, полный тест, реплей, практику, скачивание, сохранение, прерывание и защиту повреждённой истории.
- `tests/scenes.html` в режиме разработки открывает каталог для визуальной проверки; в production он не включается.
- `node scripts/browser-check.mjs` сохраняет снимки и создаёт иконки PWA из собственного SVG-логотипа.
- `node scripts/offline-check.mjs` проверяет production-сборку на порту 4173 с отключённой сетью, включая полный тест и сохранение.
- `node scripts/accessibility-check.mjs` проверяет девять состояний интерфейса через axe-core; путь к локальному `axe.min.js` задаётся в `AXE_PATH`.
- `node scripts/scenes-check.mjs` отрисовывает все 48 сцен и сохраняет контактные листы в `/tmp`.

Графическая сцена требует WebGL. На устройствах без него отображается сообщение. Системное уменьшение анимаций учитывается всегда, дополнительные анимации можно отключить в настройках.
